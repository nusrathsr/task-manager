# Task Manager

A simple Task Manager web app built with React (Vite) and React-Bootstrap.  

## Features
- User authentication (signup, login, logout using localStorage)
- Add, view, edit, delete tasks
- Toggle task completion
- Search tasks by title/description
- Filter tasks (All, Completed, Not Completed)
- Private routes with `PrivateRoute`
- Nested routing (`/tasks`, `/tasks/:id`, `/tasks/:id/edit`)
- Theme toggle (light/dark)
- State persistence in localStorage
